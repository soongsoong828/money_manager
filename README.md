# 머니로그

React, TypeScript, Vite로 만든 한국어 개인 돈 관리 모바일 웹앱입니다.

홈에서 생활비 기준액과 남은 예산, 저축 목표, 다가오는 일정을 볼 수 있습니다. 요약 카드를 눌러 소비 분석, 일정 관리, 저축 목표 상세 화면으로 이동합니다. 모바일에서는 하단 메뉴에서 홈으로 돌아갈 수 있습니다.

## 실행하기

Node.js 22.12 이상이 설치된 터미널에서 이 저장소 폴더를 열고 실행합니다.

```bash
npm ci
npm run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 엽니다. 스마트폰 화면으로 확인하려면 브라우저 개발자 도구에서 기기 모드를 켭니다. 클라우드에서 포트 미리보기 기능을 사용할 수 있다면 `npm run dev -- --host 0.0.0.0`으로 실행하고 5173번 포트를 선택합니다.

## 파일 둘러보기

- `src/data.ts`에 화면에 쓰이는 가상 예산, 거래, 일정, 저축 목표가 있습니다. 예시 금액을 변경하면 화면에서 결과를 확인할 수 있습니다.
- `src/App.tsx`에 각 화면과 이동, 월별·연도별 전환, 일정 추가 및 수정 동작이 있습니다.
- `src/styles.css`가 화면의 색상, 간격, 모바일과 데스크톱 배치를 정합니다.
- `index.html`과 `src/main.tsx`에서 앱이 시작됩니다. `package.json`과 `package-lock.json`에는 실행 명령과 패키지 정보가 들어 있습니다.

## 빌드 확인

```bash
npm run build
npm run preview
```

첫 명령은 TypeScript를 검사하고 배포용 파일을 `dist/`에 만듭니다. 두 번째 명령으로 빌드 결과를 [http://localhost:4173](http://localhost:4173)에서 확인할 수 있습니다.

## 가상 데이터

예시 화면은 2026년 11월 23일을 기준으로 표시됩니다. 추가하거나 수정한 일정은 현재 탭에서만 유지되며 새로고침하면 초기화됩니다. 앱에는 계좌 연결이나 외부 API 호출이 없습니다.
